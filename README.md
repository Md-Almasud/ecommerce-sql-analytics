## Ecommerce-SQL-Analytics
SQL based Ecommerce Sales and Customer Analytics project using MySQL

## Project Overview

This project analyzes an e-commerce database using MySQL to identify
sales trends, customer behavior, product performance, and order insights.

The project covers database creation, data management, SQL queries,
and business-oriented analysis.

## Database Tables

The project contains the following tables:

- Customers
- Categories
- Products
- Orders
- Order Items
- Payments
- Reviews
